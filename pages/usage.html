让 CapsLock 多帮你做点事。Put your CapsLock key to work.

capslock_p2 让你按住 CapsLock 就能移动光标、选中文字，也能快速打开程序、找文件和查单词。先记住几个常用键，用到什么再学什么。With capslock_p2, hold CapsLock to move the cursor and select text, or quickly open apps, find files and look up words. Start with a few shortcuts and learn the rest as you need them.

先记住这个按法How to press a shortcut

看到 CapsLock + Q，就是按住 CapsLock，再按一下 Q，然后松开。松开后照常打字。单独短按 CapsLock，仍然切换大小写。When you see CapsLock + Q, hold CapsLock, tap Q, then release. Type normally once you let go. A quick tap of CapsLock on its own still toggles capital letters.

第一次用，先试这三步Try these three steps first

  1. 打开程序Launch the app

    安装后打开 capslock_p2，看到任务栏右下角的程序图标，就可以开始用了。Open capslock_p2 after installing it. Its icon in the Windows system tray means it is running.

  2. 试着移动光标Move the cursor

    打开记事本，输入一行字。按住 CapsLock，再按 S 或 F，光标就会向左或向右移动。Open Notepad and type a line. Hold CapsLock and press S or F to move left or right.

  3. 看看设置Explore Settings

    按 CapsLock + F12 打开设置，按自己的习惯调整。基础快捷键可以直接用；翻译和 AI 需要先填写服务信息。Press CapsLock + F12 to open Settings and make it your own. Basic shortcuts work straight away; online translation and AI need service details first.

日常会用到的几个工具Tools for everyday tasks

下面这些，都可以从键盘叫出来。All of these are a shortcut away.

CapsLock + Q

打开程序、搜索网页Open apps and search the web

打开 qbar 搜索框，输入程序名，用 ↑ ↓ 选中结果，再按 Enter 打开。中文应用支持拼音首字母和全拼前缀，例如输入 wyy 找到“网易云音乐”；英文应用支持单词首字母，例如输入 vs 找到 Visual Studio Code。输入 bing 天气 可以搜索网页。Open the qbar search box and type an app name. Chinese apps support pinyin initials and full-pinyin prefixes, so wyy finds NetEase Cloud Music. English apps support word initials, so vs finds Visual Studio Code. Choose a result with ↑ ↓, then press Enter. Type bing weather to search the web.

CapsLock + Q

找电脑里的文件Find files on your PC

在 qbar 输入 e、everything、find 或 f，回车打开独立搜索页；输入 e 报告 会把“报告”带入搜索框。页面支持类型筛选、Everything 语法和右键复制/定位。Type e, everything, find or f in qbar to open the independent search page. e report carries “report” into the search box. The page supports type filters, Everything syntax, and context-menu copy/reveal actions.

CapsLock + T

查单词、翻译选中文字Look up words and translate text

先选中文字，再按快捷键：词典收录的英文单词会直接显示释义，其他文字进入翻译。翻译支持固定目标和两种语言互译；互译时可在面板选择原语言、目标语言并交换方向。没有选中文字时，会打开空白翻译面板供你输入。在线翻译需要先在设置中配置服务。Select some text, then press the shortcut. An English word found in the local dictionary shows its definition; other text opens in Translate. Translation supports a fixed target or bidirectional language pairs; in pair mode, choose the source and target in the panel and swap them when needed. With nothing selected, an empty Translate panel opens for you to type. Set up a service in Settings for online translation.

CapsLock + Q

问 AI，也可以接着追问Ask AI and follow up

在 qbar 输入 ai 帮我写一封请假邮件，按回车开始对话。回答后可以继续追问。第一次使用，先按 CapsLock + F12，在设置中填写 AI 服务信息。Type ai Help me write a leave request in qbar and press Enter. You can follow up in the chat. Before your first question, press CapsLock + F12 and enter your AI service details in Settings.

CapsLock + C / CapsLock + V

留住两份常用内容Keep two things ready to paste

用 CapsLock + C 复制、CapsLock + V 粘贴第一份内容。两边都多按住一个左 Alt，就是第二份；例如 CapsLock + LAlt + C 复制第二份。平常的 Ctrl + V 用来粘贴系统剪贴板。Use CapsLock + C to copy and CapsLock + V to paste from the first clipboard. Hold left Alt as well for the second, for example CapsLock + LAlt + C to copy. Your usual Ctrl + V pastes from the system clipboard.

CapsLock + Tab

少打几遍重复的话Expand text you type often

在设置的「Tab 替换」中添加一个缩写和完整内容，例如把 addr 设为常用地址。以后输入 addr，再按 CapsLock + Tab，就能替换成完整地址。Add an abbreviation and its full text under Tab replacements in Settings, for example addr for your address. Type addr, then press CapsLock + Tab to expand it.

CapsLock + F12

想调整？打开设置就好Make it yours in Settings

程序运行时，按住 CapsLock，再按 F12，即可打开设置中心。也可以右键任务栏右下角的程序图标，选择「设置」。While the app is running, hold CapsLock and press F12 to open Settings. You can also right-click its system tray icon and choose Settings.

  • 改按键：在「快捷键」中查看和调整自己的组合键。Change shortcuts: review and adjust key combinations in Shortcuts.
  • 启用翻译和 AI：填入所用服务提供的 API 地址、密钥和模型；翻译也可以选择有道或火山引擎，并填写对应凭据。Set up translation and AI: enter the API address, key and model from your provider. For translation, you can also choose Youdao or Volcengine and supply its credentials.
  • 设置常用工具：添加文本替换、常用网址和程序，或给常用窗口绑定数字键。Set up your tools: add text replacements, website and app shortcuts, or assign number keys to frequently used windows.

修改后记得点「保存」。大多数设置会立即生效；开机自启动也可以在托盘右键菜单中开启。Click Save when you are done. Most changes take effect immediately. You can also enable launch at startup from the tray menu.

第一次用，可能会想问A few things you might wonder

需要先设置才能用吗？Do I need to configure anything first?

移动光标、选择文字、独立剪贴板和本地词典可以直接用。在线翻译和 AI 需要你自己的服务信息，服务商可能收费。按 CapsLock + F12 就能开始设置。Cursor movement, text selection, the extra clipboards and local dictionary work straight away. Online translation and AI need your own provider details, and the provider may charge for use. Press CapsLock + F12 to set them up.

文件搜索为什么弹出管理员提示？Why does file search ask for administrator permission?

文件搜索使用 Everything。程序会优先尝试使用已经运行的 Everything；需要启动内置版本时，可能出现管理员确认，建立索引也需要一点时间。File search uses Everything. The app first tries an already running copy. Starting the bundled copy may ask for administrator permission, and building the file index can take a little time.

快捷键没反应，先看哪里？What if a shortcut does nothing?

先确认程序正在运行，任务栏右下角有它的图标。按组合键时要一直按住 CapsLock。部分笔记本的 F1–F12 默认是音量或亮度键，需要同时按 Fn，或开启 Fn Lock。Check that the app is running and its tray icon is visible. Keep CapsLock held while pressing the other key. On some laptops, F1–F12 control volume or brightness by default; hold Fn too, or enable Fn Lock.

下载的是源码，怎么启动？How do I run the source version?

安装 AutoHotkey v2 后，双击 capslock_p2.ahk。如果工具面板提示缺少 WebView2，请安装 Microsoft Edge WebView2 Runtime。Install AutoHotkey v2, then double-click capslock_p2.ahk. If a tool panel reports that WebView2 is missing, install the Microsoft Edge WebView2 Runtime.

capslock_p2 是基于 Capslock+ 的 AutoHotkey v2 重写项目，沿用它的快捷键思路，并加入翻译、AI 等工具。以 GPL v2 许可开源。capslock_p2 is an AutoHotkey v2 rewrite of Capslock+, keeping its shortcut approach and adding tools such as translation and AI. Open source under GPL v2.
