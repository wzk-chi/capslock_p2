AutoHotkey v2 · 脱胎于 Capslock+（GPL v2）

一个 CapsLock，一层快捷键。

按住 CapsLock，字母区立刻变成移动、选择与编辑的控制层；点按 CapsLock，一键切换大小写或输入法。 再配上 qbar 启动器、翻译词典、AI 问答、Everything 搜索与三组独立剪贴板——常用操作不再离开键盘。

按住 = 临时快捷键按住 CapsLock 不放，字母区暂时变成功能键：按 S 光标左移，按 J 向左选中文本，按 Q 打开 qbar。松开手指，恢复平常打字。
点按一下 = 一个快捷动作只点一下、不碰其他键，触发一个动作：默认切换大小写。很多人会把它改成「切换中英文输入法」（示例配置就是这么设的）。

What you get

它有什么用

这版是对原版 Capslock+ 的 AutoHotkey v2 重写：同款键层思路，UI 换成现代 WebView2 面板，再加上几个原版没有的新工具。

键层导航 / 选择 / 编辑

方向、按词、按行、选到行首行尾、删词删行——原生 v2 速度，干净利落。加 Alt 就是增强版（见按键节）。

qbar 启动器

输入即过滤：启动程序、打开网址、搜索（内置引擎+自定义）、浏览路径、Everything 文件搜索，选中文本自动预填。

翻译 · 词典 · AI 问答

三引擎翻译（LLM 流式优先，有道、火山兜底），多段文本保留分段；单个英文单词自动查本地 4.9 万词词典；AI 问答支持多轮追问。

Everything 即时搜索

边输入边出结果，支持原生查询语法（*.pdf、ext:pdf），Ctrl+回车直接在资源管理器定位。

独立剪贴板 + 窗口绑定

三组槽位复制粘贴互不覆盖；1~0 秒切绑定窗口，绑定跨重启保留。

配置热重载 + 屏幕自适应

改 capslock_p2.ini 保存即生效，无需重启；面板窗口随屏幕缩放，自动跟随系统明暗主题。

记住一条规则就够：多数功能键加上 Alt，就是它的「增强版」。

Get started

快速开始

一行配置都不用改就能用；想微调时，配置是活的。

运行

  • 源码运行：装好 AutoHotkey v2 后双击 capslock_p2.ahk，托盘出现图标即成功。
  • Windows 10 用户顺手装一下 WebView2 Runtime（Win11 自带）。

开机自启

右键托盘菜单「开机自启动」一键开启；或写 [Global] autostart=1。重装程序不会丢你的配置。

配置文件

一切在这一个文件里：capslock_p2.ini。参考抄写完整示例 capslock_p2-settingsDemo.ini。改完保存，0.5 秒内自动重新加载。

Everything（可选）

本机已运行就直接用；没有则自动拉起内置实例，首次建索引需一次管理员确认。不配置也完全不影响其他功能。

Straight answers

常见问题

原版说明书经常坦率地写失败模式，我们也照做。

它与原版 Capslock+ 是什么关系？

这是对 Capslock+（AHK v1 源码，GPL v2）的 AutoHotkey v2 重写。键层思路、Alt 增强规则、Tab 热串、winbind、qbar 这些核心保留；UI 面板改成 WebView2，并新增 LLM / 有道 / 火山三引擎翻译、AI 多轮问答、Everything 即时搜索、屏适应窗口。原版文档见 capslox.com/capslock-plus。

内置 Everything / 安装包被杀软报警怎么办？

Everything 命令行工具和单文件安装包是启发式查杀常客，通常是误报。源码可自行查验；首次运行 Everything 只需一次管理员确认建立索引，之后随程序启停。

选区读取的取舍

读取选中文本用的是剪贴板快照。按原版规则，以换行结尾的选区会先视为「在 IDE 复制了整行」而丢弃（避免误触）；qbar 预填与翻译多段会针对多行选区放行。完整选中一行再按 qbar 时可能把当前行预填进去，这是不吞真选区的代价。

计算器会算错吗？

CapsLock+Tab 用表达式求值（失败回退 JavaScript）。浮点运算存在尾差属正常范围，复杂业务计算建议再用真算式核对一遍。
