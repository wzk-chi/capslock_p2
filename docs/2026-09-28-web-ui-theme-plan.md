# Web 页面统一绿色主题执行计划

## 目标与边界

将全部六个正式 Web 页面及预览页统一为优雅、简约的绿色风格。深浅色自动跟随系统，不提供手动切换或持久化主题偏好。保留页面原有用途、布局职责和操作流程。

- 统一背景、文字、绿色强调色、控件、圆角、阴影、边框及交互状态。
- 减少装饰性副标题和重复说明，不新增宣传文案、统计数据或功能。
- 预览页只作为视觉参考：不把其中的模拟统计、跨功能侧栏、动画选项等引入正式页面。
- 保留必要操作提示、快捷键说明、错误原因、国际化文本及许可证/来源信息。
- 保留业务 `id`、`data-*`、DOM 事件依赖、消息协议、键盘行为、输入焦点、滚动和窗口尺寸约束。
- 唯一允许的 JavaScript 改动是删除使用介绍页独立的手动主题逻辑；其余业务脚本保持原样。
- 不改 `lib/`、`capslock-plus/`、个人配置或第三方依赖；不删除文件，不编写测试，不启动或运行脚本，不自动打包。

## 已核实的实施条件

1. `pages/` 有 `settings.html`、`translate.html`、`chat.html`、`dictionary.html`、`qbar.html`、`usage.html` 和 `ui-preview.html`。

3. `usage.html` 包含 `#theme`、`data-theme` 和 `cp2-theme` 本地存储逻辑；预览页通过 `#theme-dark` 复选框切换。两者都需改为媒体查询。

5. qbar 的 CSS 几何值与 `lib/features/qbar/qbar.ahk` 同步，不能被共享控件样式覆盖。

## 主题实现约定

- 每页在现有 `<style>` 前引用 `<link rel="stylesheet" href="theme.css">`。
- 共享变量使用 `--ui-*` 前缀。页面现有变量可以映射到共享变量，避免一次重命名导致遗漏。
- 共享文件负责颜色、字体、圆角、阴影和焦点样式；页面局部 CSS 负责布局、尺寸和专用组件。
- 不在共享文件给所有 `button`、`input`、`textarea`、`main` 强加高度、内边距、宽度或布局，以免破坏 qbar 和紧凑窗口。
- 删除或替换旧的颜色声明及媒体查询中的冲突值，避免仅叠加覆盖层而留下多套主题来源。
- 默认 `:root` 为浅色；在 `@media (prefers-color-scheme: dark)` 内覆写主题变量，并分别设置 `color-scheme: light` / `dark`，同步原生控件颜色。
- 不增加主题 JS、配置项、宿主消息或 `localStorage` 读写；系统切换由 CSS 媒体查询响应。
- 将强调文字颜色与实心按钮背景分开：深色主题可用亮绿文字，但白字主按钮必须使用深绿背景。悬停、按下状态也遵守此规则。
- 普通文字对比度目标至少 4.5:1，大号文字至少 3:1；必要控件边界和焦点提示至少 3:1。最终值按前景与实际背景核对，不能只照抄预览变量。
- 聚焦状态使用可见的 `:focus-visible`；状态不能仅靠颜色区分。保留禁用状态与正常按钮的差异。
