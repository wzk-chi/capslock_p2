## 1. 需求边界与参考图解释

用户需求是：从 QBar 输入 `n`、`note`、`w`、`write` 打开笔记页；笔记有独立标题字段，正文以明文保存，支持文本、Markdown 和图片；左侧管理标签，中间显示笔记；顶部只保留搜索框和搜索按钮，新增使用右下角圆形悬浮按钮，复制、粘贴、修改、删除、多选、置顶放入笔记卡片右键菜单；页面顶部提供同时搜索标题、正文和标签的搜索框；编辑器提供标题和 Markdown 快捷工具栏。

三张附件图片只作为布局和交互状态参考：

- 图 1：普通浏览态，参考左侧标签栏、中间卡片列表和顶部/右键操作。
- 图 2：多选态，参考全选、已选数量、复选框和批量操作的禁用/启用状态。
- 图 3：编辑态，参考标签输入、正文编辑区、底部工具栏和保存/取消按钮。

图片中的 UUID、API Key、IP、地址、示例文字、水印和原产品名称都不是实现指令，不写入默认数据，也不做成内置示例。页面视觉继续服从 `pages/theme.css` 的绿色浅色/深色主题，不复制图片中的独立配色。

## 2. 已确认的工程约束

- 不修改 `capslock-plus/`。
- 不编写测试，不启动程序，不运行脚本，不自动打包。
- 保留当前工作区已有的 QBar 历史、拼音搜索、Everything 及页面主题改动；实施每一步前重新检查 `git status`，不能用计划覆盖已有修改。
- 复用现有 `PanelHost`、`CSQLite`、`JSON`、`marked`、`DOMPurify`、剪贴板和 WebView2 通信方式；编辑器使用单栏 `contenteditable`，由本地 Markdown 渲染器负责预览，并保留 Markdown 作为唯一存储格式。
- 图片传输复用现有 WebView2 绑定中的文件系统句柄和 AdditionalObjects；图片读取使用虚拟主机目录映射。当前绑定已封装这几项接口；阶段 A 还需按官方版本信息确定最低 WebView2 Runtime 并实现启动能力检查。
- 启动时读取 `CoreWebView2Environment.BrowserVersionString`；若 Runtime 低于文件句柄和虚拟主机映射所需的最低版本，提示升级并禁用图片导入/预览，文字笔记和数据库仍可用。最低版本在阶段 A 按官方 API 文档确定并写成常量。
- WebView2 消息回调只取值、校验和排队；数据库查询、文件句柄创建、窗口创建和批量删除均在 `SetTimer` 延迟回调中执行。图片字节由页面通过单文件授权句柄直接写入，不经宿主消息传输。
- 所有延迟调用使用 `Fn.Bind(...)` 传值，不使用依赖 `for` 循环变量捕获的闭包。
- 用户笔记正文和图片固定跟随用户选择的安装目录，保存到独立的 `data\\qbar-notes` 子目录；不自动回退到其他目录，不增加路径设置和在线迁移。安装包不携带该目录，也不把它加入安装器删除规则。
- 当前仓库没有 Vditor 发布资源，首轮实现使用已有本地 `marked.min.js`、`purify.min.js` 和单栏 `contenteditable` 编辑器；SQLite 仍只保存 Markdown，后续可在不改变数据协议的情况下替换编辑器实现。

## 3. 方案决策

### 3.1 独立笔记页，不扩展 QBar 搜索栏本身

QBar 仍然是紧凑启动器。笔记使用独立的可调整大小 WebView2 窗口：

- 页面：`pages/qbar-notes.html`。
- AHK 模块：`lib/features/qbar/qbar_notes.ahk`。
- 打开函数：`NotesShow(initialSearch := "", targetHwnd := 0, recordHistory := true)`。
- 窗口标题：`capslock_p2 笔记`。
- 初始尺寸约为 `1000x720`，最小尺寸约为 `760x520`，使用 `+Resize +MinimizeBox +MaximizeBox +SysMenu +ToolWindow`。
- 失焦不自动隐藏。标题栏关闭只隐藏窗口并保留页面/编辑草稿，重新打开继续当前编辑；编辑态按 Esc 等同取消并在有未保存更改时确认，浏览态按 Esc 隐藏窗口。只有应用退出时销毁 WebView，避免“关窗保留草稿”却同时结束编辑会话的矛盾。

### 3.2 数据存储：SQLite 正文 + 原始图片文件

使用现有 `resources/SQLite3.dll` 和 `CSQLite.ahk`，固定保存到：

```text
<安装目录>\data\qbar-notes\qbar-notes.db
<安装目录>\data\qbar-notes\media\<asset-id>
```

安装目录不可写时直接提示“请把程序安装到可写目录”，不静默换到 C 盘或其他目录。当前 `.iss` 只列出程序资源，没有匹配 `data\qbar-notes` 的 `[Files]` 或 `UninstallDelete`；同一安装目录的更新/覆盖安装不会覆盖数据库和图片。用户把程序安装到另一个目录时，需要在程序关闭后手动复制整个 `data\qbar-notes` 目录。

理由：

- 标题、Markdown 正文、标签关系和置顶状态全部存入 SQLite；正文不加密、不上传网络，搜索可以直接由 SQLite 查询。
- 图片作为原始文件保存在 `media` 目录；数据库只保存图片 ID、笔记归属、MIME 和相对路径。
- 图片不经过 Base64，也不设置应用级图片大小或数量上限；JS 使用 WebView2 授权的文件句柄写原始 `Blob`，页面阅读时从受控的本地虚拟主机地址加载原图。
- 数据库和媒体目录位于安装目录的专用数据子目录，升级或同一目录重新安装不会覆盖笔记。
- Markdown 图片引用使用 `asset:<id>` 内部标记。读取笔记时，AHK 将有效资产 ID 转成映射到 `media` 目录的本地 URL；页面只能访问这个媒体目录，不获得安装目录其他文件的访问权。

首版支持编辑器粘贴剪贴板图片和选择本地图片文件。每次导入时 AHK 为新图片创建唯一文件，并只把该文件的写入句柄交给当前页面；JS 将原始 `Blob` 写入文件后发送完成消息。写入或关闭失败时不插入图片引用、清理不完整文件并提示错误；磁盘空间不足等文件系统错误照常显示，不设置应用级大小/数量上限。取消编辑会删除本会话未关联的图片；保存时 SQLite 事务写入正文和资产关系，失败保留编辑草稿及其图片供重试。程序异常中断留下的孤立文件，在数据库成功打开、版本检查和完整资产查询成功后再清理。

复制/粘贴到外部窗口只复制 Markdown 文本，图片引用转换成替代文字；本期不提供笔记到笔记的复制动作。

### 3.3 QBar 别名规则

四个别名统一走一个 `QbarNotesAlias()` 判断：`n`、`note`、`w`、`write` 不区分大小写。与现有内置 `q`、`e` 规则一致：

- 用户已在 QRun/QWeb/QSearch 配置同名短键时，配置项优先，笔记别名不抢占用户配置。
- 输入裸别名时打开笔记页。
- 输入 `n 关键词`、`note 关键词`、`w 关键词` 或 `write 关键词` 时打开笔记页，并把 `关键词` 放入顶部搜索框。
- 打开笔记页时写入一条 `notes` 类型的 QBar 历史，保存实际搜索词而不是四个别名；历史重放重新打开笔记页并恢复搜索词，不把它当作普通程序启动项。普通打开和历史重放通过 `recordHistory` 参数区分，避免重放再次生成历史。
- 入口统一调用 `NotesShow(initialSearch := "", targetHwnd := 0, recordHistory := true)`；历史重放传 `recordHistory := false`，QBar 路由传入打开前保存的目标窗口句柄。
- QBar 必须先隐藏，再通过 `SetTimer(NotesShow.Bind(searchText, targetHwnd, recordHistory), -1)` 创建/显示笔记页，不能在 WebView2 消息回调内同步创建第二个 WebView2。

## 4. 数据模型

首次连接数据库时创建 schema，并通过 `PRAGMA user_version` 做版本迁移。每次连接启用 `PRAGMA foreign_keys = ON` 和适度的 busy timeout。所有建库和迁移都在事务中执行：完整成功后才更新版本号，失败时回滚并保留原数据库；发现高于当前支持版本时直接报错并停止写入，不能重建空库覆盖原文件。建议 schema 如下：

```sql
CREATE TABLE IF NOT EXISTS notes (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  title       TEXT NOT NULL DEFAULT '',
  content_md  TEXT NOT NULL DEFAULT '',
  pinned      INTEGER NOT NULL DEFAULT 0,
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS tags (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  name        TEXT NOT NULL COLLATE NOCASE UNIQUE,
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS note_tags (
  note_id     INTEGER NOT NULL REFERENCES notes(id) ON DELETE CASCADE,
  tag_id      INTEGER NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (note_id, tag_id)
);

CREATE TABLE IF NOT EXISTS note_assets (
  id            TEXT PRIMARY KEY,
  note_id       INTEGER NOT NULL REFERENCES notes(id) ON DELETE CASCADE,
  relative_path TEXT NOT NULL,
  mime          TEXT NOT NULL,
  original_name TEXT NOT NULL DEFAULT '',
  created_at    INTEGER NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_notes_updated ON notes(pinned DESC, updated_at DESC, id DESC);
CREATE INDEX IF NOT EXISTS idx_note_tags_tag ON note_tags(tag_id, note_id);
CREATE INDEX IF NOT EXISTS idx_assets_note ON note_assets(note_id);
```

当前 schema 版本为 2。版本 1 数据库在事务中创建无旧备注列的新 `notes` 表，复制标题、正文、置顶和时间字段后替换旧表，并保留标签关系与图片资产关系；迁移失败则回滚，遇到更高版本直接停止读写。

约定：

- `title` 是独立的普通文本字段，允许为空；列表标题显示该字段，空标题显示“无标题”，正文摘要单独显示。
- `content_md` 保存用户实际编辑的原始 Markdown，不保存渲染后的 HTML；标题不混入正文。
- 搜索覆盖标题、正文和关联标签名称；数据库不保留额外备注列。
- `pinned = 1` 的笔记排在未置顶笔记之前，同组按 `updated_at DESC` 排序；这里的“置顶”只表示笔记在列表中置顶，不改变窗口 AlwaysOnTop 状态。
- 删除标签只删除标签和关联，不删除笔记；删除笔记时先记住资产文件路径，再在事务中删除笔记、关系和资产记录，事务成功后删除图片文件。
- 图片文件删除失败不回滚已成功的笔记事务，也不要求保留已删除的资产行；下次启动扫描媒体目录和数据库引用，清理孤立文件，不能因为图片清理失败让正文丢失。
- 编辑器产生的新图片先写成无数据库归属的图片文件；保存成功时仅为正文仍引用的图片建立资产记录，并删除本会话其余未引用草稿图片；取消编辑时删除全部草稿图片。保存事务失败时保留图片和正文草稿供重试。
- 编辑时移除已有图片，先在事务中更新 Markdown 和资产关系，事务成功后再删除不再引用的文件；事务失败时保留原文件。文件扩展名由允许的 MIME 类型映射生成，不使用用户文件名拼接磁盘路径。
- 图片 ID 和磁盘相对路径由 AHK 生成；页面提交的文件名仅作为显示元数据，不能决定落盘路径。
- SQL 中所有用户文本必须经过统一的字符串/LIKE 通配符转义；不能把页面传来的正文、标签名或搜索词直接拼接进 SQL。

## 5. 页面交互设计

### 5.1 普通浏览态

浏览态使用标签栏和笔记列表两列；新增使用右下角圆形悬浮按钮，笔记操作通过卡片右键菜单完成：

```text
┌──────────────────────────────────────────────────────────────┐
│ 搜索标题 / 正文 / 标签                                      │
├──────────────┬───────────────────────────────────┬───────────┤
│ 全部/标签列表 │ 便签标题 + 正文预览                │
│ 标签 1        │ 点标题进入编辑                     │
│ 标签 2        │ 右键打开复制/粘贴/修改/删除菜单    │
│ ...           │                                   │
│ [+][改][删]   │                                   │
└──────────────┴───────────────────────────────────┘
```

编辑态保留左侧标签栏和中间编辑页面；编辑页面顶部提供“返回”。保存或返回后回到浏览列表。

- 左栏显示“全部”“无标签”和标签列表；标签栏标题下方靠顶部放置添加、修改、删除标签按钮，不放在栏底。
- 单击标签只改变过滤条件；搜索框再对标题、正文和标签做全文子串匹配。
- 浏览列表在中间按笔记显示独立标题和受高度限制的 Markdown 纯文本预览；点击标题直接进入共用编辑态，单击任意预览行复制该行，双击同一行粘贴该行。预览行本身就是点击目标，不额外显示复制按钮、图标或操作说明；行高和内边距保持紧凑的普通文本密度。正文图片只解析登记在本库中的 `asset:<id>`；外部图片 URL 不自动加载，避免浏览笔记时产生意外网络请求。
- 便签通常数量不多，首版不分页：一次加载所有匹配笔记的标题、标签和受高度限制的正文摘要；只有进入编辑时才读取完整正文和资产。排序为 `pinned DESC, updated_at DESC, id DESC`。
- 顶部搜索框使用 150–250ms 防抖，页面给每次查询递增 `queryId`，只接受最新结果；进入编辑或返回列表不清空搜索、标签条件、选中项和列表滚动位置。
- 浏览态右下角显示圆形新增按钮；卡片右键菜单显示复制、粘贴、修改、置顶、删除和多选。编辑态顶部显示返回按钮。操作使用现有主题颜色、圆角、阴影、焦点环和 `aria-label/title`，不依赖只有颜色才能识别的状态。

右键菜单动作定义：

| 动作 | 浏览态行为 |
|---|---|
| 粘贴 | 将当前选中笔记按 Markdown 转义后的 `# 标题`、空行、正文的格式写入系统剪贴板并发送一次 `Ctrl+V` 到打开 QBar 前记录的目标窗口；标题为空时只复制正文，不包含标签。没有有效目标或没有选中笔记时只保留剪贴板并提示。 |
| 复制 | 将当前选中笔记按 Markdown 转义后的 `# 标题`、空行、正文的格式写入系统剪贴板；标题为空时只复制正文，不包含标签，内部图片引用转成替代文字。 |
| 添加笔记 | 打开空白编辑器。 |
| 修改 | 仅单选时进入共用编辑态并载入标题、完整正文、标签和图片引用。 |
| 删除 | 单选时确认后删除；选中态下可批量删除。 |
| 多选 | 进入/退出浏览列表的多选模式。 |
| 置顶 | 单选时切换列表置顶；多选时若存在未置顶项则全部置顶，否则全部取消置顶，不改变窗口置顶状态。 |

“粘贴”在隐藏笔记页后执行。QBar 打开时保存当前外部窗口 HWND，`NotesShow` 接收这个 HWND；操作前确认窗口仍存在并重新激活，激活失败时不发送 `Ctrl+V`。继续复用现有剪贴板序号保护，不能覆盖用户在操作期间产生的新剪贴板内容。

### 5.2 多选态

- 浏览列表每条笔记显示复选框；左侧标签栏顶部显示“全选”和“已选 N”。
- 多选按钮使用主题强调色表示当前状态；再次点击退出多选并清空临时选择。进入编辑态时退出多选。
- 多选态中点击笔记条目只切换该笔记的勾选状态，单行复制暂不可用，避免一次点击同时触发选择和复制。
- 没有选中项时，复制、粘贴、修改、删除、置顶按图 2 的语义显示为禁用或不可用。
- 有选中项时：复制按稳定顺序拼接各笔记的 Markdown 转义后 `# 标题` 和正文（空标题省略标题行），并将内部图片引用转成替代文字；删除弹出数量确认；置顶执行批量规则；修改和粘贴仅在恰好单选时启用。
- 首版不分页，显示全部匹配的轻量摘要；全选只选择当前搜索和标签过滤结果。查询使用 `pinned DESC, updated_at DESC, id DESC`，保证时间相同的笔记顺序稳定。
- 切换标签、刷新搜索、进入编辑、保存/删除成功或关闭页面时清空多选，避免旧 ID 作用于新列表。
- 批量删除使用数据库事务，页面只有收到成功响应后才移除卡片；失败保留原选择和列表。

### 5.3 编辑态

编辑器直接切换为笔记页的页面内编辑态，不创建遮罩/对话框，也不创建第二个 WebView2 窗口；新增和修改共用同一个编辑页面：

1. 顶部提供独立的普通文本标题输入框，标题允许留空；其下是可输入标签的 chips 控件，支持输入已有标签、回车创建/选中标签、退格删除最后一个标签；不提供编程语言选择器。
2. 正文区使用单栏 `contenteditable`，呈现所见即所得编辑，不出现 Markdown 源码/预览分栏。SQLite 的 `content_md` 仍保存 Markdown，标题单独存入 `notes.title`；载入时用本地 `marked` 展开 Markdown 和受控图片 URL，保存时将编辑区 HTML 转回 Markdown，并把图片 URL 规范化回 `asset:<id>`。保存前校验所有资产 ID 属于当前笔记或当前编辑会话。
3. 顶部快捷栏只显示加粗、斜体、删除线、标题、引用、列表、代码块、链接和图片等按钮；不提供编程语言选择器，不出现源码/预览分栏。页面负责常用 HTML 与 Markdown 节点之间的转换。
4. 图片选择/粘贴入口使用 WebView2 文件句柄：取得 File/Blob 后请求 AHK 创建单文件写入句柄，JS 将原始 Blob 写入；写入流关闭成功并收到宿主确认后，才把虚拟主机图片 URL 插入编辑器。每个编辑会话中的上传有唯一 requestId，用于关联句柄、完成/失败和取消消息。未完成的写入不能保存；失败时清理部分文件并提示，可重新导入。图片数量和大小不设应用级上限。
5. 底部提供取消和保存；`Ctrl+S` 保存，`Esc` 取消（有未保存更改时先确认）。编辑器打开时由 AHK 创建唯一 `editorId`；取消、保存成功或应用退出时使其失效。取消时页面先中止正在写入的流，再通知宿主清理本会话图片；迟到的句柄/完成消息必须拒绝并清理对应文件。标题栏关闭只隐藏窗口，不结束 editorId 或清除草稿；保存期间禁用保存、取消、切换笔记和隐藏窗口。成功回包必须更新当前笔记 ID、更新时间和图片引用后才解除锁定。
6. 浏览列表显示转义后的纯文本预览行；编辑器初始内容使用本地 `marked` + `DOMPurify` 渲染规则。AHK 先将已登记资产引用映射为专用虚拟主机 URL；禁用不安全原始 HTML、清理粘贴内容，并只允许库内图片资产作为图片源。

## 6. AHK ⇄ 页面消息协议

所有消息是 JSON 字符串，页面到 AHK 使用 `type` 字段，AHK 侧继续使用 `LLMMessageParse`、`LLMMsgField` 和数值/布尔校验。

页面到 AHK 的最小消息集合：

| type | 主要字段 | 处理 |
|---|---|---|
| `ready` | 页面尺寸 | 标记 page ready，发送标签和首次列表。 |
| `beginEdit` | `noteId`（新建时为空） | AHK 创建新的 `editorId`，读取已有笔记（如有），返回编辑器初始数据。 |
| `query` | `queryId`, `text`, `tagId` | 延迟执行搜索；校验 session/query 序号，返回全部匹配笔记的轻量标题和预览行。 |
| `copyLine` | `noteId`, `text` | 校验笔记 ID 和纯文本行后复制该行；页面收到结果后显示轻提示。 |
| `pasteLine` | `noteId`, `text` | 校验笔记 ID 和纯文本行后隐藏笔记页，并将该行粘贴到打开 QBar 前记录的目标窗口。 |
| `saveNote` | `editorId`, `saveSeq`, `noteId`, `title`, `content`, `tagIds`, `assetIds` | 校验编辑会话及该笔记/会话拥有的资产；宿主按 editorId/saveSeq 加互斥和去重，在事务中保存标题、正文、标签和资产归属，返回成功或失败结果。 |
| `deleteNotes` | `noteIds` | 校验 ID 数组，确认由页面完成，AHK 再执行事务。 |
| `setPinned` | `noteIds`, `value` | 单条或批量更新置顶。 |
| `copyNotes` | `noteIds` | AHK 从数据库取标题和正文，以 Markdown 转义后一级标题加正文的格式写入系统剪贴板；内部图片引用转成替代文字，不包含标签。 |
| `pasteNote` | `noteId` | AHK 取标题和正文、隐藏页面、执行受保护的系统粘贴。 |
| `addTag` / `renameTag` / `deleteTag` | `tagId`, `name` | AHK 校验名称、处理唯一性/确认后的删除并刷新标签。 |
| `assetStart` | `editorId`, `requestId`, `mime`, `name` | 仅接受活动编辑会话；延迟创建唯一图片文件和只对此文件有写权限的 WebView2 句柄。成功时 AHK 回发 `assetHandle` JSON 消息并附带句柄；失败时清理部分文件并以 `assetWriteResult(ok: false)` 返回错误。页面从同一消息事件的 `additionalObjects` 读取句柄并按三项 ID 匹配。 |
| `assetWritten` | `editorId`, `requestId`, `assetId`, `ok` | 页面在原始 Blob 写入流关闭后报告成功或失败；AHK 校验三项均匹配当前待处理请求，成功才标记为可保存资产并确认，失败则清理部分文件。重复完成消息幂等处理，不重复创建资产行。 |
| `assetCancel` | `editorId`, `requestId`, `assetId`（可空） | 取消待处理请求；若句柄尚未回包，迟到回包必须丢弃并清理文件；若正在写入，页面先 abort/close，再通知宿主清理。 |
| `cancelEdit` | `editorId` | 结束编辑会话并清理全部未关联图片；页面先 abort 所有写入流，宿主进入 canceling 状态，迟到句柄和完成回包一律拒绝；清理完成后确认取消。 |
| `hide` | 无 | 隐藏笔记页面但保留页面及编辑草稿；保存进行中时拒绝隐藏并让页面继续等待结果。标题栏关闭走同一隐藏逻辑。 |

AHK 到页面统一使用 WebView2 消息，不通过字符串拼接调用页面函数：

- 普通 JSON 消息以 `type` 区分 `setNotes`、`setTags`、`openEditor`、`assetWriteResult`、`actionResult` 和 `setHostState`。其中 `openEditor` 携带 editorId、笔记 ID、标题、Markdown、标签和已登记图片 URL；`assetWriteResult` 携带 editorId/requestId/assetId、成功状态和可选错误。
- `assetHandle` 使用 `PostWebMessageAsJsonWithAdditionalObjects` 发送 JSON 和一个文件句柄；页面在同一个 `message` 事件中读取 JSON 与 `event.additionalObjects`，确认 ID 匹配后才写入。图片字节不进入消息体。
- `setNotes` 携带匹配笔记的标题、预览行、总数、过滤条件和选择状态；`setTags` 携带标签、使用数量和当前标签。
- 页面只在收到匹配的成功 `assetWriteResult` 后，才在编辑区插入图片引用；已取消或过期请求不写入。
- `actionResult` 用于复制、粘贴、保存、删除和标签操作的成功/失败提示；`setHostState` 用于语言、数据库降级状态和页面重新加载后的初始化状态。

过期查询结果可以丢弃；保存结果必须由宿主记录，即使页面暂时隐藏也不能丢弃。每个 editorId/saveSeq 只允许提交一次，重复消息返回已记录结果而不重复插入；失败后重试使用新的 saveSeq。保存成功时宿主更新当前 noteId、只关联正文实际引用的图片并清理其余草稿图片，然后使 editorId 失效；保存失败时返回错误、解除保存锁并保留编辑器及图片草稿。隐藏/重显不会结束 editorId；应用退出才销毁页面并使其失效。重新显示时刷新列表，但不丢弃仍打开的编辑草稿。

| 首次启动 | 在安装目录 `data\\qbar-notes` 创建 SQLite schema 和媒体目录；安装目录不可写时明确报错，不创建第二个数据源。 |
| 数据库不可写/损坏 | 显示错误并保留当前页面可关闭；不能重建空库、清空或覆盖已有数据库文件。 |
| WebView2 Runtime 过旧 | 按启动时版本检查提示升级并禁用图片导入/预览；纯文字/Markdown 笔记仍可用，不调用不支持的文件句柄或映射接口。 |
| 数据库迁移 | 每次迁移在事务中执行；失败回滚并保留原版本；遇到更高版本提示不支持并停止读写，不重建或覆盖数据库。 |
| 搜索 | 标题、正文、标签名任一命中即可；标签过滤和搜索可以同时生效。 |
| 标题 | 新建/编辑可独立读写标题；标题不写入 Markdown 正文，空标题有明确显示。 |
| 快速连续搜索/列表返回 | 旧 queryId 结果不能覆盖最新列表；编辑页返回后恢复原搜索、标签过滤和列表位置，排序稳定。 |
| 单行快速复制/粘贴 | 浏览列表中单击某条预览行复制该行纯文本，双击同一行粘贴该行；点击标题直接进入编辑。 |
| 编辑页返回 | 编辑态只显示左侧标签栏和中间编辑页面；点击顶部返回回到浏览列表并保留原搜索、标签条件和列表状态。 |
| 笔记列表加载 | 首版不分页；一次只加载所有匹配笔记的轻量标题和预览行，完整正文和图片在进入编辑时按需读取。 |
| 标签改名/删除 | 关系保持或解除正确；删除标签不删除笔记。 |
| 新增/编辑保存 | 标题、原始 Markdown、标签、置顶和更新时间一致保存；标题不混入正文。 |
| 保存期间关闭/重发 | 保存按钮、取消、切换笔记和隐藏窗口均被锁定；同一 editorId/saveSeq 重发返回已记录结果，不重复插入；成功回包更新 ID 后才解除锁定。 |
| 取消编辑 | Markdown 草稿不写入数据库；当前编辑会话新建的图片文件被删除，已有图片不受影响。 |
| Markdown 编辑 | 单栏 contenteditable 以所见即所得方式显示；保存后正文仍是 Markdown，重开能还原格式，不出现源码/预览分栏。 |
| Markdown 阅读/安全 | 只读区与编辑器初始内容使用同一 `marked` + `DOMPurify` 规则；原始 HTML 和不安全链接被禁用或清理，外部图片不自动加载，渲染失败回退纯文本。 |
| 图片写入 | JS 使用 AHK 授权的文件句柄写入原始 Blob；字节不经过 JSON/Base64；不设应用级大小或数量上限。 |
| 图片读取 | 保存后通过映射到媒体目录的虚拟主机 URL 加载原始文件；缺图不丢正文，也不允许 Markdown 读取任意本地路径。 |
| 单选复制/粘贴 | 复制标题（若非空）和正文 Markdown，不把标签混进去；外部剪贴板中的图片引用转成替代文字；目标窗口无效时不发送粘贴。 |
| 多选复制 | 按稳定顺序拼接选中笔记的标题（若非空）和 Markdown 正文，并将图片引用转成替代文字。 |
| 批量删除 | 先确认，再事务删除；失败时页面不假装删除。 |
| 置顶 | 单选/多选只改变笔记列表排序，不改变窗口 AlwaysOnTop。 |
| 页面隐藏/重开 | 隐藏不结束 WebView/editorId，未完成查询结果失效但当前编辑草稿保留；保存成功回包落宿主状态，重新显示刷新列表且不重复插入。 |
| 应用退出 | 停止定时器、解除 WebView2 事件、关闭数据库连接，不删除用户数据库；未完成/未关联图片由下次安全启动清理。 |
| 打包/更新/重装 | 安装包只包含程序资源，不包含 `data\\qbar-notes`；同一路径更新不会覆盖数据库或图片，换安装目录由用户手动复制数据目录。 |

## 10. 明确不在本期范围

- 不做云同步、跨设备同步、加密、账户体系、协作和网络 API。
- 不做笔记导入/导出、回收站、版本历史和全文 FTS5 索引；首版用 SQLite `LIKE` 查询，数据量变大后再单独设计迁移。
- 不做任意外部目录图片管理；只管理本页粘贴或选择并写入安装目录媒体目录的图片。图片不设应用级大小和数量限制。
- 不做自动回退、可配置数据路径或在线迁移；程序只使用当前安装目录的数据目录。
- 不新增编程语言选择器，不将编辑器改造成代码运行环境。
- 不修改图片中的示例数据，不把原产品的水印、品牌或无关按钮照搬进页面。

## 11. 实施完成标准

用户能够通过四个 QBar 别名打开独立笔记页，在统一绿色主题下完成标题和标签管理、搜索标题/正文/标签、Markdown 编辑、原始图片插入、复制/粘贴、增删改、多选和置顶；标题、Markdown 正文与标签等元数据以明文保存在安装目录 `data\\qbar-notes` 的 SQLite 中，只有图片字节保存在该目录的 `media` 子目录。图片经 WebView2 文件句柄写入并由虚拟主机映射读取，不经过 Base64，也不设应用级图片大小或数量上限。静态审查完成后，交付说明必须区分“代码已静态核对”和“因项目约束尚未运行验证”的部分。
