# 长按连发设计与实施说明

日期：2026-10-10

状态：已实现；按项目要求只做 AHK 语法校验，不运行应用或测试。

## 1. 交互与行为

设置中心增加独立的“长按连发”页。页面顶部开关即时启动或关闭长按连发；CapsLock + F8 控制同一个状态，切换后页面开关同步更新。该运行状态只保存在内存中，程序重启后关闭。没有录制按键时，开关不可用，按 CapsLock + F8 不会启动并提示先录制按键。

模式启动后，按住配置的键盘键或鼠标按键，首次按下正常生效。键盘的系统重复按下被抑制，达到启动延迟后才按配置的间隔发送重复输入；松开立即停止本次连发，但模式仍保持启动。再次按 CapsLock + F8 关闭模式，并停止当前连发。启动延迟从该按键按下时开始计时，与页面开关和 CapsLock + F8 无关。

默认连发按键为鼠标左键；默认启动延迟为 500 毫秒，范围 0–5000；默认连发间隔为 100 毫秒，范围 20–2000。连发按键只支持单个键盘键或鼠标左键、右键、中键、侧键 1、侧键 2，不支持组合键、修饰键、CapsLock、滚轮或游戏杆输入。连发输出每次都是完整的按下/松开或点击，鼠标点击位置取每次输出时的指针位置。

运行状态只保存在内存中，程序重启后默认关闭。开始录制或保存连发配置时，只取消正在进行的按住任务，已启动状态保持不变；录制期间暂停接管按键。用户关闭开关、输入发送失败或程序退出时，停止当前任务并关闭连发模式。

## 2. 设置页

设置页复用现有设置导航、主题和统一保存/取消流程，不新建独立窗口或保存协议。字段顺序如下：

| 顺序 | 控件 | 规则 |
| --- | --- | --- |
| 1 | 长按连发开关 | 即时控制运行状态；CapsLock + F8 与其互相同步；不参与设置保存 |
| 2 | 连发按键 | 默认鼠标左键；可录制为单个键盘键或鼠标按键，也可清空 |
| 3 | 启动延迟（毫秒） | 默认 500，范围 0–5000 |
| 4 | 连发间隔（毫秒） | 默认 100，范围 20–2000 |

开关说明应明确：开关与 CapsLock + F8 是同一个运行状态的两种控制方式。启动后按住录制的按键，延迟从按下该键时开始计时，达到延迟后连发，松开停止本次连发。页面在设置项下方仅在需要时显示“请先录制按键”“已启动，等待按住连发按键”“已按住，N 毫秒后开始连发”或“正在连发：按键”；模式关闭时不显示状态文字。不使用单独的“启停快捷键”状态卡。

点击“录制”后，同一个按钮立即变为“取消”。录制期间按下一个键或点击鼠标按键可录制；左键点击“取消”按钮取消录制并保留原草稿。其他位置的左键可以录制为连发按键。取消设置或取消录制不修改已保存配置。录制期间 CapsLock + F8 不改变连发模式。

录制候选由一个对象保存，页面和窗口外的鼠标输入共用按下、松开处理。InputHook 就绪后才接受候选；初始按住的键释放后恢复抑制。取消时只等待已抑制的键松开，其余输入正常传递。页面在消费取消点击时立即清除按压记录，click 和 auxclick 共用同一清理入口。

CapsLock + F8 在快捷键列表中显示为固定的“启动 / 关闭长按连发”。全局或应用配置里已有的旧映射保留但不执行；宿主拒绝新增或修改该保留项。

## 4. 计时和失败处理

每次只允许一个长按任务和一个活动 timer。按键、发送参数、延迟、间隔、timer 和 generation 集中保存在任务快照中；发送参数在注册钩子时构造。按下后启动单次延迟计时，延迟为 0 时安排下一次可调度回调，不使用 SetTimer(callback, 0)。第一次输出后，同一个 timer 按设定间隔重复。松开、配置改变、关闭或失败时统一取消 timer 并清空快照；配置改变后保留已启动状态。回调绑定 generation 来丢弃过期任务。定时回调同时检查物理按下状态和配置快照，避免松开或配置改变后继续输出。

键盘按下钩子阻止系统连发，首次按下使用 SendInput 回送 down，物理松开透传；若回调到达时已经松开，则回送完整按下/松开，避免残留按下状态。定时输出使用完整 SendInput，保留用户当前修饰键状态；鼠标按键使用完整 Click。发送级别为 0，键盘钩子使用 $ 前缀避免再次触发。周期回调只读取内存，不访问数据库、不逐次写日志或发送页面消息。状态只在启停、等待开始、正式开始或停止时推送。

截图中的“输入错误，已停止”对应日志中的 SendLevel(-1) 参数错误。AHK SendLevel 不接受负值；实现改为有效的 0 级发送，键盘钩子同时使用 $ 前缀避免重复触发。运行日志记录模式切换、钩子注册、按住触发、首次输出和松开停止，不记录每次间隔输出。若输出仍异常，立即关闭模式、写入详细诊断日志并提示用户。

启动延迟和间隔是目标时间，实际调度可能稍晚；延迟后不补发积压输入。程序不使用忙等、Sleep 或高频轮询。

## 5. 验收要点

- 页面标题和导航名为“长按连发”，顶部首先显示运行开关；页面不再显示“启停快捷键”卡片。
- 开关和 CapsLock + F8 操作同一个运行状态，任何一方切换后另一方同步显示。
- 配置中没有连发按键时，运行开关不可用；按 CapsLock + F8 不启动，并提示先录制按键。
- 只有模式开启后，按住录制输入才会连发；物理按下先正常传递，持续按住达到延迟后才重复，松开立即停止当前任务。
- 启动延迟从录制输入的按下开始计时；默认 500 毫秒，与运行开关及 CapsLock + F8 无关。
- 鼠标左键、右键、中键及两个侧键可录制并连发；滚轮不出现在录制支持范围，也不会被作为长按输入拦截。
- 点击“录制”后按钮变为“取消”；左键点击取消按钮取消录制并保留原草稿；其他位置的左键可录制。
- 取消点击后普通单击正常生效；新录制等待旧按键松开期间不接受鼠标候选；初始按住的键释放后，再次录制同一键仍会抑制其原有动作。
- 配置保存和开始录制会取消当前按住任务，但保持开关已启动；录制期间按键不会触发连发。关闭开关、发送失败和退出程序会停止任务并关闭模式；失败日志包含异常细节。
- 鼠标点击是完整点击；松开后没有残留按下状态；鼠标移动会改变后续点击位置。
- 按 CapsLock + F8 时不触发普通映射；旧的全局或应用专属映射原样保留且不执行。
- AHK 源码修改完成后按仓库 AGENTS.md 的 PowerShell /validate 命令检查退出码和全部警告；不编写测试、不运行脚本或启动应用。
